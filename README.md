# Portfolio de Marc Zaragoza

Portfolio personal de Marc Zaragoza, ingeniero en Telecomunicaciones.

## Contenido

- Presentacion y datos de contacto.
- Proyectos de tecnologia, electronica y Arduino.
- Estudios en telecomunicaciones, electronica y programacion.
- Skills de hardware, software y desarrollo web.
- Selector de tema claro/oscuro y espanol/ingles.

## Estructura

```text
index.html
images/
scripts/main.js
styles/main.css
```

## Ejecucion local

El proyecto es estatico. Puede abrirse directamente con `index.html` o servirse desde cualquier servidor HTTP local.

La pagina utiliza Swiper desde jsDelivr para los carruseles de proyectos y Devicon para algunos iconos de Skills.
